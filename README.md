
# Active Directory Deployment & User Lifecycle Management

## Project Overview

This project involves designing and deploying an
on-premises Active Directory Domain Services 
environment using Windows Server 2022.

The objective is to build a functional Windows domain
environment and demonstrate practical skills in:

- Active Directory Domain Services
- DNS configuration
- Organisational Unit (OU) design
- Group Policy Management
- User and group administration
- PowerShell automation
- Identity and Access Management (IAM)
- User onboarding, modification and offboarding
- Access control and security

## Project Objectives

1. Deploy and configure Windows Server.
2. Install the AD DS server role.
3. Promote the server to a domain controller.
4. Configure Active Directory-integrated DNS.
5. Design an OU structure.
6. Create users, security groups and delegated permissions.
7. Implement Group Policy.
8. Develop PowerShell scripts for user management.
9. Demonstrate the complete user lifecycle.
10. Validate security and functionality.

## User Lifecycle Management

The project will demonstrate:

- Joiner: Creating new user accounts and assigning
  appropriate group memberships.
- Mover: Modifying user attributes, departments and
  access permissions.
- Leaver: Disabling accounts, removing access and
  documenting account decommissioning.
